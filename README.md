# سيرفر الكافيه

## التشغيل على جهازك للتجربة
    node server.js
افتح http://localhost:3000 (محتاج Node.js إصدار 18 أو أحدث، ومفيش مكتبات تتثبت).
أول مرة هيطلب منك تنشئ حساب الأدمن.

## النشر على الإنترنت
ارفع المجلد على GitHub، وبعدين على Render أو Railway أو Fly.io (Web Service):
- Build command: (سيبه فاضي)   Start command: `node server.js`
- **لازم تضيف Disk / Volume دائم** وتضبط المتغير `DATA_FILE` على مساره (مثلاً `/data/data.json`)،
  لأن الحفظ في ملف، والتخزين المؤقت في الباقات المجانية بيتمسح مع كل إعادة تشغيل.
- بديل أرخص وأبسط: سيرفر VPS صغير (4–6 دولار شهرياً) وتشغله بـ `pm2` أو `systemd`، ومعاه Caddy للـ HTTPS.

## إيميل لكل طلب جديد (اختياري)
اعمل حساب على resend.com وضيف المتغيرات:
`RESEND_API_KEY` و `MAIL_TO` (إيميل أو أكتر مفصولين بفاصلة) و `MAIL_FROM` (بعد توثيق الدومين).

## QR للترابيزة
اعمل QR لكل ترابيزة بالرابط: `https://موقعك/#t5` (5 = رقم الترابيزة).

## ملاحظات
- النسخة الاحتياطية: سجل دخول كأدمن وافتح `/api/backup`.
- متغيرات اختيارية: `PORT`, `TZ_NAME` (الافتراضي Africa/Cairo).
- الباسوردات مشفرة (scrypt) والجلسة صالحة 30 يوم.
